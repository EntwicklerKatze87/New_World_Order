# New World Order (NWO) Untersuchung

Dieses Repository dient als Sammlung und Analyse des Phänomens "New World Order" (NWO), einer weit verbreiteten Verschwörungstheorie.

## Zweck

- Systematische Sammlung von Informationen über die NWO-Verschwörungstheorie
- Analyse ihrer Ursprünge, Entwicklung und verschiedenen Ausprägungen
- Dokumentation von Schlüsselfiguren, Organisationen und Behauptungen
- Untersuchung der sozialen und politischen Auswirkungen

## Struktur

```
New_World_Order/
├── README.md                 # Diese Datei - Übersicht und Zweck
├── docs/                     # Hauptdokumentation
│   ├── einleitung.md         # Einführung in das Thema
│   ├── geschichte.md         # Historische Entwicklung
│   ├── konzepte.md           # Kernkonzepte und Theorien
│   └── analysen/             # Detaillierte Analysen
├── quellen/                  # Quellen und Referenzen
│   ├── literatur.md          # Bücher und Publikationen
│   ├── online.md             # Online-Quellen
│   └── medien.md             # Medienberichte
├── personen/                 # Wichtige Personen
├── organisationen/            # Organisationen und Gruppen
├── zeitlinie.md              # Chronologische Übersicht
└── forschung/                # Eigene Forschungsergebnisse
```

## Haftungsausschluss

Dieses Repository dient rein zu Forschungs- und Bildungszwecken. Die gesammelten Informationen stellen keine Bestätigung von Verschwörungstheorien dar, sondern sollen diese kritisch untersuchen und kontextualisieren.

## Beitrag

Dies ist ein Forschungsprojekt zur Untersuchung eines sozialen Phänomens.
